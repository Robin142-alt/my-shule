Schools need one consistent payment workflow across bank collections, M-Pesa, reviewed statements and manual receipts. This release adds an extensible eleven-bank registry, approved encrypted connections, implemented official Equity/KCB/Co-op sandbox protocols, durable verified ingestion and shared invoice, credit, receipt and ledger processing. Banks without accessible authorized protocols remain explicitly unavailable for native activation.

Accountants can manage unmatched funds, apply credits, request receipt moves and invoice write-offs, and reserve partial refunds for independent Principal review. Corrections preserve original receipts and academic/financial history; evidenced external payouts do not initiate bank transfers. Tenant RLS, exact money, immutable provenance, source locks and transactional audit/event persistence guard all shared workflows.

Production-schema rehearsal repairs legacy types/defaults and obsolete tenant references without clamping balances or discarding evidence. Cloudflare deployment waits for trusted Railway API and payment-worker statuses for the same commit. Existing student progression functionality is preserved.

Validation: API and frontend production builds; 94 PostgreSQL tests; 149 backend tests; 29 interface tests; 11 release/auth/environment tests; eight 390px/1440px browser journeys. Schema-only production copy passes repeated migrations and real Prisma ledger, receipt, invoice, credit, C2B replay and reconciliation operations. Live baseline and authentication/readiness checks are read-only. Browser/provider fixtures are not official bank certification.

Activation dependencies and per-bank evidence: `docs/universal-banking.md`. Release/rollback evidence: `tasks/banking/release.md`. Do not roll back to binaries that ignore populated credit-refund/correction history or perform destructive down migrations. Bank credentials, account mandates, private protocol contracts and authorized sandbox/live verification remain external requirements.
