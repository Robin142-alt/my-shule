# MyShule Role Dashboard + Sidebar Workspace Blueprint

## 0. Global Rule for Every Workspace

Every sidebar workspace in every role dashboard must follow this structure:

### A. Workspace Header

Each page must have:

**Title:** clear role-specific name
**Description:** what this workspace helps the user do
**Context bar:** school name, academic year, term, week/date, user role, scope
**Permission badge:** full access, view-only, restricted, approval required
**Module status:** active, locked, pending setup, disabled by Super Admin

Example:

> **Learner Attendance**
> Mark daily attendance, track absenteeism, notify parents, and generate attendance reports.
> Context: Term 2, 2026 · Grade 7 Blue · Class Teacher Scope

---

### B. Summary Cards

Every workspace should have 3–6 useful cards backed by real database queries.

Examples:

* Total learners
* Pending approvals
* Today’s absentees
* Unpaid invoices
* Low stock items
* Sick bay visits today
* Books overdue
* Visitors currently inside school
* Exams awaiting moderation
* Reports ready for publishing

Cards must have:

* Real values from API
* Loading skeleton
* Empty state
* Error state with retry
* Click action where useful

---

### C. Main Work Area

Every workspace must have the actual workflow tool:

* Table
* Form
* Calendar
* Kanban board
* Queue
* Report builder
* Wizard
* Detail drawer
* Approval panel
* Print preview
* Upload/import area
* Bulk action toolbar

No workspace should only show cards.
