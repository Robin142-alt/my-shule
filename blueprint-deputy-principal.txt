# Deputy Principal Dashboard — MyShule Blueprint

## Role Identity

**Role:** Deputy Principal
**Dashboard Type:** Senior School Operations Dashboard

---

# 1. Overview Workspace

## Purpose
This is the Deputy Principal’s landing page. It should show the state of the school today: attendance, discipline, staff duty, unresolved issues, timetable gaps, urgent escalations, and academic concerns.

## Top Summary Cards

1. **Today’s Learner Attendance**
   * Present
   * Absent
   * Late
   * Not marked classes
   * Button: `Open Attendance`

2. **Discipline Alerts**
   * New incidents today
   * Serious cases pending
   * Parent summons pending
   * Button: `Review Incidents`

3. **Staff Duty Status**
   * Staff on duty today
   * Missing duty reports
   * Uncovered duty zones
   * Button: `View Duty Roster`

4. **Lesson Coverage**
   * Lessons covered
   * Relief lessons needed
   * Teachers absent
   * Button: `Assign Relief`

5. **Student Welfare Flags**
   * Sick bay visits today
   * Counselling referrals
   * Repeated absenteeism
   * Button: `View Welfare Cases`

6. **Pending Approvals**
   * Leave requests
   * Discipline actions
   * Class movement requests
   * Operational escalations
   * Button: `Open Approvals`

## Main Work Area

### Section: “Today’s Priority Queue”

Table columns:
| Column           | Description                                      |
| ---------------- | ------------------------------------------------ |
| Priority         | Critical, High, Normal                           |
| Type             | Attendance, Discipline, Staff, Academic, Welfare |
| Student/Staff    | Affected person                                  |
| Class/Department | Scope                                            |
| Status           | New, In Review, Escalated, Resolved              |
| Assigned To      | Deputy, Teacher, Counsellor, Nurse, Principal    |
| Last Update      | Time                                             |
| Actions          | Row actions                                      |

### Row Actions
* `Open`
* `Assign`
* `Escalate`
* `Mark Resolved`
* `Send Message`
* `Print Summary`

### Bulk Actions
* `Assign Selected`
* `Escalate Selected`
* `Mark as Reviewed`
* `Export Selected`
* `Print Selected`

## Buttons
Primary buttons:
* `Start Morning Review`
* `Open Attendance Gaps`
* `Assign Relief Teacher`
* `Create Discipline Case`
* `Send Staff Notice`
* `Generate Daily Summary`
