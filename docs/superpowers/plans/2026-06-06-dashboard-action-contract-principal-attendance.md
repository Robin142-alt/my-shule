# Dashboard Action Contract Principal Attendance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove fake Principal Attendance button behavior and establish a testable action-contract pattern for dashboard actions.

**Architecture:** Keep the existing dashboard UI and school-scoped operational store. Add behavior in `apps/web/src/components/school/principal-practical-dashboard.tsx` so attendance actions either open real UI, open a communication confirmation, open a print preview, queue/log real school-scoped communication, or show a specific disabled reason.

**Tech Stack:** Next.js, React, Jest, Testing Library, local school operational store, existing print-preview helper.
